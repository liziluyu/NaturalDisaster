# 暴风雪实现计划

**目标：**实现已确认的暴风雪玩家效果、配置破坏列表及地表冰雪。

**边界：**效果只读取 `EventState.effectActive()` 和既有覆盖结果；不修改 `field/` 中心、事件或生命周期算法。不强加载、不补算卸载区域，不改变中心场指纹。

## 执行步骤

- [x] 添加方块选择器语法测试，覆盖 ID、tag、空值与坏条目；先运行确认缺少实现，再实现解析和启动校验。
- [x] 在 `Config` 添加 `snowStorm.breakableBlocks`，默认 `#c:glass_blocks`、`#minecraft:crops`；未知项逐条警告跳过。
- [x] 添加 `SnowStormEffects`：独立 `freezePlayer(ServerPlayer)` 仅缓慢 I、60 tick；地表按破坏→水源结冰→最多三层雪处理，一样本最多一次操作。
- [x] 服务层解析开始区块中心的生成地表群系，缓存仅为可重建派生结果；复用现有候选遍历汇总暴风雪覆盖。地表受区块 ticking 门槛和已加载邻域约束，重叠只采样一次。
- [x] 添加统一玩家效果分发，汇总后处理进入、退出、重登、换维度与重生；创造/旁观不缓慢；每20 tick补充缓慢，采样关闭不影响玩家效果。
- [x] 扩展视距载荷为“上限”模式，保留调试命令原有精确设置模式，网络协议升级，客户端保留原设置并在退出恢复。
- [x] 运行完整编译/测试，确认2项旧粗层fixture失败在HEAD基线也存在；新增选择器测试及场黄金测试通过，`assemble`打包通过，3个服务端GameTest通过。客户端视觉和自然事件端到端场景尚未实测。
- [x] 审查代码、修复发现的问题，更新主设计文档及暴风雪设计文档，记录验证范围。

## 接入决定

- 开始群系固定取开始区块中心 `(chunkX*16+8, chunkZ*16+8)`，Y 为生成器 `WORLD_SURFACE_WG` 地表高度减1，并限制到维度建造高度内；通过生成器的 biome source/noise sampler 读取，不取当前世界方块，也不获取/生成该区块。
- 破坏沿用原版掉落和正常更新层数；地表操作要求周围3×3区块均已加载，并通过同步结算作用域限制未加载区块的方块/流体/方块实体读取和方块写入。审查发现仅3×3和缩减更新层数不足以约束红石回调，已添加作用域Mixin及红石/藤蔓GameTest回归。跳过的点不补算。
- 玩家视觉使用瞬态投递记录去重（不保存中心、事件状态）；断线丢弃记录，重生对象替换或跨维度时重新发送。
- 第一版不执行随机点方块效果；原有随机采样保持，结果不持久化。
